# UwUtils
## Modules
### Object
#### Maven
```xml
<dependency>
    <groupId>io.github.anominy</groupId>
    <artifactId>uwutils-object</artifactId>
    <version>0.3-r1</version>
</dependency>
```
#### Gradle
```groovy
implementation 'io.github.anominy:uwutils-object:0.3-r1'
```
